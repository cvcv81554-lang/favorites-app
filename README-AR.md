# Favorites — دليل مختصر

تطبيق مكتبة مفضّلات شخصي (آيفون + أندرويد + Android TV) مبني بـ Capacitor 7 و JavaScript عادي.
بياناتك تبقى على جهازك فقط؛ لا يوجد في المستودع أي بيانات أو صور حقيقية.

## 1) النشر أول مرة (ويندوز / PowerShell)

افتح PowerShell داخل مجلد `favorites-app` ونفّذ بالترتيب:

```
winget install GitHub.cli
```
أغلق النافذة وافتحها من جديد، ثم:
```
gh auth login
```
(اختر GitHub.com ثم HTTPS ثم Login with a web browser)
```
powershell -ExecutionPolicy Bypass -File scripts\publish.ps1
```

السكربت ينشئ المستودع، يولّد مفتاح التوقيع مرة واحدة، يحفظه كسرّ في GitHub، يرفع المشروع، ويطبع لك رابطَي التحميل.
البناء يأخذ 10–20 دقيقة وتتابعه من تبويب **Actions** في صفحة المستودع.

> **مهم:** مجلد `signing\` فيه مفتاح توقيع الأندرويد. انسخه إلى مكان آمن. لو ضاع لن تُثبَّت التحديثات فوق النسخة القديمة.

## 2) التثبيت

روابط ثابتة لا تتغير (ضع اسم حسابك مكان `USER`):

- **APK:** `https://github.com/USER/favorites-app/releases/download/latest/Favorites.apk`
- **IPA:** `https://github.com/USER/favorites-app/releases/download/latest/Favorites.ipa`

| الجهاز | الطريقة |
|---|---|
| آيفون | في ESign أو Scarlet: استورد من رابط الـ IPA ثم وقّع بشهادتك وثبّت |
| Android TV | في تطبيق Downloader اكتب رابط الـ APK ثم ثبّت. يظهر التطبيق في الشاشة الرئيسية ويعمل بالريموت |
| جوال أندرويد | افتح رابط الـ APK نفسه من المتصفح وثبّت |

## 3) نقل بياناتك من التطبيق القديم

1. في التطبيق القديم: الإعدادات ← تصدير (ملف `vkte-backup-….json`).
2. في الجديد: الإعدادات ← النسخ الاحتياطي ← **استيراد من ملف**.
3. على التلفاز (لا يوجد منتقي ملفات): استخدم **استيراد من رابط**، أو ضع الملف في `Documents/FavoritesBackup/import` ثم **استيراد من مجلد النسخ**.

## 3ب) الشاشة (Android TV) والمزامنة من الجوال

1. ثبّت نفس ملف الـ APK على الشاشة (بتطبيق Downloader) وافتحه. تفتح **واجهة الشاشة** تلقائيًا (قائمة جانبية، أرفف، تنقل بالريموت).
2. إن كانت مكتبة الشاشة فارغة تظهر صفحة **اتصال بالجوال** وفيها رمز QR وعنوان ورمز من 6 أرقام.
3. في الجوال: **امسح رمز QR بالكاميرا**، فيفتح تطبيق المفضلة ويرسل مكتبتك كاملة بالصور.
   أو من داخل التطبيق: المزيد ← **الشاشة** ← ربط بشاشة، واكتب العنوان والرمز.
4. بعد الربط: أي تعديل في الجوال يصل الشاشة خلال ثوانٍ تلقائيًا، والتقييم أو المشاهدة على الشاشة يرجع للجوال.

الشرط: الجهازان على نفس شبكة Wi-Fi، وتطبيق الشاشة مفتوح. لا إنترنت ولا خادم خارجي؛ البيانات تنتقل داخل بيتك فقط.

**الريموت:**
- الأسهم للتنقل، و**OK** للفتح، و**رجوع** للعودة بنفس موضعك.
- **ضغطة مطوّلة على OK** (أو زر القائمة) تفتح خيارات سريعة: مفضلة، تقييم، مقارنة، عرض الصور.
- في البحث: لوحة مفاتيح على الشاشة، أو 🎤 للبحث الصوتي.

تفاصيل ما تم في نسخة الشاشة: `PROJECT_PROGRESS.md`.

## 3ج) مكتبتك داخل Nuvio (إضافة Favorites + Real-Debrid)

خادم صغير اسمه **Favorites Hub** يعمل على الكمبيوتر (مجلد `hub/`). التطبيق يرسل له مكتبتك تلقائيًا، وهو يقدّمها لـ Nuvio كإضافة.

1. على الكمبيوتر (مرة واحدة): `powershell -ExecutionPolicy Bypass -File hub\install-windows.ps1`
   يشغّل الخادم الآن ومع كل تشغيل لويندوز، ولوحة التحكم على `http://127.0.0.1:7710/`.
   ليصل الجوال والتلفاز إلى الخادم، شغّل مرة واحدة في PowerShell كمدير:
   `New-NetFirewallRule -DisplayName "Favorites Hub" -Direction Inbound -Protocol TCP -LocalPort 7710 -Profile Private -Action Allow`
2. في تطبيق Favorites على الجوال: الإعدادات ← **🎬 Nuvio** ← ربط، واكتب عنوان الكمبيوتر والرمز من اللوحة.
3. في Nuvio: الإعدادات ← Media ← Content & Discovery ← Addons، والصق **رابط الإضافة** من اللوحة ثم Install.
   على الكمبيوتر نفسه استخدم رابط `127.0.0.1`، وعلى التلفاز رابط عنوان الشبكة.
4. Real-Debrid: من اللوحة ← «ربط حساب Real-Debrid»، وافتح real-debrid.com/device واكتب الرمز. لا نطلب كلمة المرور.

**الكتالوجات في Nuvio:** ممثلاتي المفضلات، أحدث الممثلات، كل مكتبتي (مع البحث والوسوم)، قوائمك التي تختارها في اللوحة، جاهزة للمشاهدة، اقتراحات Favorites الذكية، أعمال ممثلاتي، أحدث الأعمال، القادمة، الأعمال حسب ممثلة.
صفحة الممثلة تعرض أعمالها كحلقات؛ اختر عملًا لترى مصادره.

**المصادر:** Real-Debrid ليس محرك بحث. الخادم يبحث **داخل حسابك فقط** (التورنتات المكتملة وسجل التحميلات) ويطابقها مع أعمالك بالاسم والعنوان والاستوديو والتاريخ، أو تربط أنت ملفًا أو رابطًا بعمل من اللوحة («ربط مصدر بعمل»).
العمل الذي لا يوجد له ملف في حسابك لا يظهر له مصدر.

**الخصوصية:** كل شيء على جهازك. رابط الإضافة سرّي (من يملكه يرى مكتبتك)؛ يمكنك إلغاؤه وإنشاء غيره من اللوحة. رموز Real-Debrid ورمز الربط تُحفظ مشفّرة (مفتاح محمي بحسابك في ويندوز).

## 4) التحديث

عدّل ما تريد ثم:
```
git add -A
git commit -m "update"
git push
```
يُبنى الإصدار الجديد تلقائيًا بنفس الرابطين. ثبّته فوق القديم وبياناتك تبقى.

## 5) البناء محليًا (اختياري)

```
npm install
npm run build
npm run serve
```
ثم افتح `http://127.0.0.1:5173/` (وأضف `?tv=1` لتجربة وضع التلفاز بأسهم الكيبورد).

APK محلي (يحتاج JDK 21 و Android SDK 35):
```
powershell -ExecutionPolicy Bypass -File scripts\local-apk.ps1
```
الناتج: `dist\Favorites.apk`

الاختبارات الآلية (تحتاج Edge أو Chrome): `npm test` — تصنع ملف نسخة تجريبيًا بصور مجرّدة، تستورده، وتصوّر الشاشات في `tests\out`.

## 6) أين بياناتي؟

- داخل التطبيق (IndexedDB)، والصور مخزّنة كملفات Blob منفصلة.
- نسخة تلقائية في `Documents/FavoritesBackup` (على الآيفون تظهر في تطبيق «الملفات»). عند تثبيت جديد بقاعدة فارغة تُستعاد تلقائيًا إن وُجد المجلد.
- مفاتيح الـ API ورمز القفل تبقى على الجهاز ولا تدخل أي نسخة احتياطية.

## بنية المشروع

```
src/index.html, src/app.css     الواجهة والتصميم
src/js/NN-*.js                  وحدات التطبيق (تُدمج بالترتيب في www/app.js)
src/native/index.js             إضافات Capacitor (تُحزَّم بـ esbuild)
scripts/build.mjs               البناء
scripts/patch-android.mjs       تعديل مشروع أندرويد المولَّد (TV، أيقونات، إضافة Shell)
scripts/patch-ios.mjs           تعديل مشروع iOS المولَّد (الملفات، الأيقونة، تغطية الخلفية)
.github/workflows/build.yml     البناء والنشر التلقائي
hub/server.mjs, hub/lib/*.mjs   خادم Favorites Hub: المزامنة + إضافة Nuvio + Real-Debrid
hub/admin.html                  لوحة تحكم الخادم (من الكمبيوتر فقط)
tests/hub.mjs                   اختبار الخادم والإضافة من البداية للنهاية
```
مجلدا `android/` و `ios/` لا يُحفظان في المستودع؛ يولَّدان في كل بناء بـ `npx cap add` ثم يُعدَّلان بالسكربتين.
